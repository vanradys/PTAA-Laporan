Tambahkan fitur Project Schedule & PO Deadline Monitoring.

Tujuan:
Fitur ini digunakan untuk memantau PO yang masuk, target penyelesaian project/tugas dari PO tersebut, sisa hari menuju deadline, status ketercapaian PO bulan berjalan, dan notifikasi jika melewati deadline.

Fitur yang harus dibuat:

1. Data Project Schedule dari PO
Setiap PO/project harus punya data:
- No PO
- Nama Project
- Customer
- Tanggal PO Masuk
- Target Penyelesaian
- Deadline / Due Date
- PIC / Departemen terkait
- Status Project:
  - Belum Mulai
  - Proses
  - Hampir Deadline
  - Delay
  - Selesai
  - Close
- Progress %
- Catatan

2. Hitung sisa hari deadline
Sistem otomatis menghitung:
- Berapa hari lagi menuju deadline
- Apakah sudah melewati deadline
- Berapa hari keterlambatan jika delay

Contoh tampilan:
- “Deadline 21 hari lagi”
- “Deadline 7 hari lagi”
- “Terlambat 3 hari”

3. Warna indikator deadline
Gunakan badge/row color:

- Hijau:
  Jika deadline masih di atas 3 minggu / lebih dari 21 hari.

- Kuning:
  Jika deadline tersisa 2 minggu atau kurang / 8–14 hari.

- Merah:
  Jika deadline tersisa 1 minggu atau kurang / 1–7 hari.

- Merah terang / lebih mencolok:
  Jika sudah melewati deadline / delay.

Rules warna:
- > 21 hari = Hijau
- 8 sampai 14 hari = Kuning
- 1 sampai 7 hari = Merah
- < 0 hari / lewat deadline = Merah terang dan status Delay

Jika deadline sudah 15–21 hari, boleh tampilkan warning ringan atau tetap hijau muda sesuai style UI existing.

4. Notifikasi deadline
Buat notifikasi otomatis untuk:
- PO mendekati deadline 2 minggu
- PO mendekati deadline 1 minggu
- PO sudah melewati deadline
- PO belum close padahal target penyelesaian sudah lewat

Isi contoh notifikasi:
- “PO [No PO] - [Nama Project] tersisa 14 hari menuju deadline.”
- “PO [No PO] - [Nama Project] tersisa 7 hari menuju deadline.”
- “PO [No PO] - [Nama Project] sudah melewati deadline selama [jumlah hari] hari.”

Notifikasi dikirim ke:
- PIC terkait
- Departemen terkait
- HR/Admin/Director
- Role yang punya akses fitur project schedule / PO monitoring

Notifikasi harus tersimpan permanen, bukan hanya toast.
Unread count tetap muncul setelah reload sampai dibaca.

5. Status Close
Jika project/PO sudah selesai:
- User berwenang bisa klik “Close”
- Status menjadi Close
- Setelah Close, PO tidak lagi dihitung sebagai pending/delay aktif
- Tapi tetap masuk histori dan laporan bulanan

6. Monitoring PO bulan berjalan
Tambahkan summary card:
- Total PO Bulan Ini
- PO Selesai Bulan Ini
- PO Belum Selesai
- PO Delay
- Persentase Pencapaian PO Bulan Ini

Rules:
- Default tampilkan data bulan berjalan sesuai kalender saat website dibuka.
- Jika user filter bulan/tahun, summary mengikuti bulan/tahun tersebut.
- Hitung apakah PO bulan ini sudah tercapai atau belum berdasarkan:
  PO selesai / total PO bulan tersebut x 100%

7. Filter Project Schedule
Tambahkan filter:
- Bulan
- Tahun
- Tanggal PO masuk
- Deadline
- Status Project
- PIC
- Departemen
- Customer
- No PO
- Nama Project
- Search keyword

8. Tabel Project Schedule
Kolom tabel:
- No PO
- Nama Project
- Customer
- Tanggal PO Masuk
- Target Penyelesaian
- Deadline
- Sisa Hari
- Progress %
- Status Project
- PIC
- Departemen
- Aksi

Di kolom Sisa Hari:
- tampilkan badge warna hijau/kuning/merah/merah terang sesuai sisa deadline.

9. Integrasi dengan Laporan Harian
Jika memungkinkan:
- Project dari PO bisa dipilih saat mengisi tugas harian.
- Tugas harian yang terkait PO bisa mempengaruhi progress project schedule.
- Di detail PO, tampilkan laporan harian yang terkait dengan PO tersebut.
- Di laporan harian, tampilkan project/PO yang sedang dikerjakan.

10. Hak Akses
- Semua departemen boleh melihat project schedule.
- PIC/departemen terkait boleh update progress/catatan.
- HR/Admin/Director boleh melihat semua, memberi review, dan close.
- User biasa tidak boleh close PO jika tidak punya permission.
- Backend API wajib validasi permission, jangan hanya hide tombol di frontend.

11. UI Bahasa Indonesia
Semua label, button, status, empty state, toast, validation, dan tabel wajib Bahasa Indonesia.

Contoh:
- Project Schedule → Jadwal Project
- Deadline → Tenggat Waktu
- Due Date → Batas Waktu
- Close → Tutup
- Delay → Terlambat
- Progress → Progres
- Remaining Days → Sisa Hari
